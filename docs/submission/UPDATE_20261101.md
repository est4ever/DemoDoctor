## Real Analysis and scientific limitations

Self-service Real Analysis is implemented. Ordinary DemoDoctor remains offline and
Dry Run remains the default. One-time local opt-in/provider configuration and an
adequate ledger cap are required; each video then uses Import Footage, estimate
review and explicit Analyze approval without developer assistance. Keys remain
backend-only. Readiness checks configuration presence, not account authentication,
credit or provider availability. Estimates are not provider-enforced billing caps.

No new paid/provider call or genuine unseen-video experiment was performed for
this update. Mocked end-to-end completion does not prove new-video accuracy.
EP005 orientation is an existing Muse hypothesis, not a verified detector result;
its outcome remains uncertain. EP003's recorded success is narrower 2D containment,
not verified physical orientation. Grasp/release and task completion require their
own support. Missing evidence does not force an outcome. Indie-track eligibility
for the October 24 foundation still requires organizer/owner confirmation.
