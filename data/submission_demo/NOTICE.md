# Recorded demonstration package

This package contains **recorded real SAM 3.1 results**, not mock inference.
It creates no provider requests. Historical Muse Spark Open output is AI-generated
and remains bound to its original evidence package. Reconstructed claims have no
new Muse response. Do not treat model prose as independently verified fact.

Media sources, both labeled Apache-2.0 by their publishers:

- `kantine/BotFails`, revision `3478e49d91e1737eb76dfee2d81bb22617039c13`,
  dish-tidy-up test episodes 003, 005, 006, 010, 013, logitech_1 camera.
  https://huggingface.co/datasets/kantine/BotFails
- `ankithreddy/so101_pickplace_uno`, revision
  `f47dcf21b0bf8bd0f83cec8fd74755c65dfc012b`, episode 000000, top camera.
  https://huggingface.co/datasets/ankithreddy/so101_pickplace_uno

Changes by DemoDoctor: compact H.264 display transcodes (CRF 28), audio omitted;
all original frames, frame rate, dimensions and image-coordinate measurements
are retained. SAM overlay videos contain recorded model mask annotations.
`MANIFEST.json` lists exact source and distributed file hashes and frame counts.
These lossy display derivatives do not replace original scientific source files.

Pilot JSON is a publication subset: local paths, raw transport payloads, request
and response identifiers, usage/cost records and private job metadata are excluded.
Evidence summaries, claim values, uncertainty and citation/catalog bindings remain.
`audit/before` and `audit/after` are separate contexts; E IDs are not global IDs.
No robot joint measurements are added to the video-only pilot.

The Apache-2.0 license text is provided in `LICENSE-APACHE-2.0.txt`. Source metadata
and attribution are also preserved under `data/lerobot/*/SOURCE.json`.
Model outputs are subject to the applicable Meta Model API and Fireworks terms,
linked in `docs/submission/THIRD_PARTY.md`; no model weights are distributed.
