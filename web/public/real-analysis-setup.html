Local Real Analysis setup

Ordinary DemoDoctor starts offline. Dry Run is always the default in Import Footage. No inference runs at startup, upload preparation or refresh.

  1. Install the Python and React dependencies described in the project README.
  2. Set MODEL_API_KEY (Meta) and FIREWORKS_API_KEY (Fireworks) in the backend environment or a private, Git-ignored .env. Never enter credentials in this browser. Configuration detection does not authenticate an account or check credits.
  3. Stop managed offline services with DemoDoctor-Stop. Start DemoDoctor -RealAnalysis. An explicit -CredentialsFile C:\private\providers.env can load an existing file into the backend process. These flags also work with scripts\start-demodoctor.ps1.
  4. The existing default $1 run limit is below the full-context Muse reservation ($1.32 before SAM). The owner can explicitly set a limit at startup, for example DemoDoctor -RealAnalysis -PerRunBudgetUsd 2.10. This changes only the per-run limit in the existing ledger; it does not reset spend or raise the total budget. Reconciliation of unknown charges is required before further inference.
  5. Choose a video, task, object noun phrase, destination noun phrase and window (maximum 30 seconds). Use a single camera, not a multi-view composite. Select Real Analysis, review the file hash, exact frame window, operations and estimate, then explicitly approve Analyze.

The estimate is conservative admission accounting at published standard rates, not a provider-enforced billing guarantee. There are zero automatic paid retries. A lost connection should recover the same job, not start another one. All jobs remain local.

Video-only inputs do not provide measured gripper opening or release. Raw destination footprints have no calibrated interior, and assume a stationary camera/target. The outcome detector is all objects in target; it does not verify drawer closure, pouring or arbitrary instructions. Uncertainty is an intended result.

Never expose this local inference API publicly. Ordinary DemoDoctor preserves offline behavior. Stop the real session before switching back.
