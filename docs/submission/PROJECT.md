# DemoDoctor

**Evidence-grounded failure analysis for robot demonstrations.**

DemoDoctor helps robotics builders answer three questions: what was observed,
what can reasonably be inferred, and what remains unknown? It combines recorded
Meta SAM 3.1 object tracks with robot measurements when available, independently
checks structured claims, and gives Muse Spark Open a bounded evidence package
for citation-based explanations. The React investigation desk synchronizes video,
SAM annotations, timestamps and source evidence.

The main contribution is inspectable reasoning about physical behavior. A
confident video narrative is not a substitute for measured evidence. DemoDoctor
preserves observation gaps, missing target geometry and uncertain outcomes.

## Paste-ready short description

DemoDoctor is a robotics investigation workspace powered by Meta SAM 3.1 and
Muse Spark Open. It connects video to object tracks, independently checked claims
and cited explanations. Builders can inspect what was observed, what was inferred
and why a task verdict remains uncertain. Six recorded demonstrations run without
API credentials. Uploads default to a free dry run; explicitly enabled local Real
Analysis uses the existing pipeline after provider setup and per-job cost approval.
Saved diagnostic hypotheses remain unverified. Fresh-provider generalization has
not been validated by this update.
